# alloy-thermo-skill

A self-contained **Claude Agent Skill** for running Monte Carlo thermodynamics
simulations of multicomponent / high-entropy alloys (HEAs) on HPC and
interpreting the results.

It packages a modern C++17 + MPI **parallel-tempering** lattice Monte Carlo
engine together with Python tooling so that an AI agent (or a human) can:

1. **Prepare inputs** from a composition and DFT-derived pair (cluster-expansion)
   interactions,
2. **Submit** a SLURM job (one MPI rank per temperature replica),
3. **Analyze** the output — plot energy, specific heat, susceptibility,
   Warren-Cowley short-range order, and Binder cumulant, and estimate the
   **order-disorder transition temperature**.

The model works for **any number of elements** (>= 2) on **BCC / FCC / SC**
lattices; the geometry is data-driven and generated automatically.

## Quick start

```bash
# build
cd engine && make && cd ..

# prepare inputs from a spec (see examples/MoNbTaW/spec.json)
python scripts/make_inputs.py examples/MoNbTaW/spec.json --outdir run/

# run locally (8 temperature replicas) ...
cd run && mpirun -n 8 ../engine/alloy_mc control.input 2024 && cd ..
# ... or submit to SLURM (see references/hpc.md)

# analyze
python scripts/analyze.py --dir run/ --out run/analysis
```

## Engine design notes

This is a ground-up C++17 rewrite of a legacy 4-element HEA Monte Carlo code.
Key changes:

- **Any number of elements** at run time (was a compile-time `#define NE 4`).
- Modular, RAII C++17 with a single seedable RNG (`std::mt19937_64`) replacing
  three mixed legacy generators; reproducible per `(seed, rank)`.
- Data-driven lattice geometry (BCC/FCC/SC) generated by `make_inputs.py`.
- Portable build (`make`/CMake) with no machine- or TensorFlow-specific paths;
  dead neural-network code removed.
- Self-describing CSV output with named columns; a serial self-test verifies the
  incremental energy bookkeeping against a from-scratch recomputation.

The physics — pair-interaction Hamiltonian, composition-conserving Kawasaki
moves, Metropolis acceptance, and replica exchange — is preserved from the
original. See `references/physics.md`.

## Requirements

- A C++17 compiler and MPI (`mpic++` / `mpicxx` / Cray `CC`).
- Python 3.8+ with `numpy` and `matplotlib` for the helper scripts.
